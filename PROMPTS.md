# Prompt-Vorlagen

Fertige Prompts für wiederkehrende Aufgaben. `[[ … ]]` ersetzen und einfügen.

> Faustregel: Der erste Prompt enthält so viel Kontext wie möglich. Das spart
> Nacharbeit.

---

## 1. Mail beantworten

```
Entwirf eine Antwort auf die letzte Mail von [[Name / Firma]]. Zieh den Verlauf
und alles, was du im CRM dazu findest. Ton wie in TONE-OF-VOICE.md. Nur als
Entwurf zeigen, nicht senden.
```

## 2. Termin vorbereiten

```
Bereite mein Gespräch mit [[Name / Firma]] am [[Datum]] vor. Zieh Mails, Kalender,
Notizen in Meetings/ und CRM-Daten zusammen. Gib mir: aktuellen Stand, was die
andere Seite vermutlich will, 3 Punkte, die ich ansprechen sollte, mögliche
Einwände und den nächsten konkreten Schritt. Kompakt.
```

## 3. Meeting nachbereiten

```
Hier meine Notizen aus [[Meeting]]: [[Stichpunkte einfügen]].
Mach daraus eine Notiz in Meetings/, trag die Aufgaben in TASKS.md ein und
entwirf eine kurze Follow-up-Nachricht an die Teilnehmenden. Entwurf nur zeigen.
```

## 4. Wochenrückblick

```
Was ist diese Woche passiert? Geh TASKS.md, Projects/ und Meetings/ durch und
gib mir: was erledigt ist, was hängt, was nächste Woche zählt. Schlag vor, was
ich streichen oder delegieren kann.
```

## 5. Idee challengen

```
Ich überlege, [[Idee / Vorhaben]]. Sei kritisch: Was spricht dagegen, was fehlt,
wen habe ich vergessen, was ist der größte Risikofaktor? Dann: Wie würdest du es
stattdessen machen?
```

## 6. Prozess dokumentieren

```
Ich erkläre dir jetzt, wie [[Prozess]] bei uns läuft. Stell mir Rückfragen, bis
du ihn vollständig verstanden hast, und schreib dann eine Schritt-für-Schritt-
Anleitung in Completed/. Markiere Stellen, die unklar geblieben sind, mit ⚠️.
```

---

_Erweitern nach Bedarf. Was du oft tippst, gehört hier rein._
