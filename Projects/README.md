# Projects/

Ein File pro Projekt: Stand, Beteiligte, Entscheidungen.

## Vorlage

```markdown
# [Projektname]
- **Ziel:** [eine Zeile]
- **Status:** [In Arbeit / Pausiert / Fertig]
- **Owner:** [Name]
- **Beteiligte:** [Namen]
- **Stand:** JJJJ-MM-TT

## Aktueller Stand
[wo das Projekt gerade steht]

## Entscheidungen
- JJJJ-MM-TT: [Entscheidung], weil [Grund]

## Offene Fragen
- [Frage]

## Verlauf
- JJJJ-MM-TT: [was passiert ist]
```

## Wann ein Projekt-File anlegen

- Alles, was länger als zwei Wochen läuft
- Alles mit mehreren Beteiligten
- Alles mit Entscheidungen, die man später wiederfinden will
- Alles, wo Claude bei „Wie ist der Stand bei X?“ Kontext braucht
